# EcoSense 🌱

**Project**  EcoSense
**Domain** Waste Management

## 🌏 What is EcoSense?
EcoSense is an AI-enabled waste management prototype that helps users identify common household waste items and understand the appropriate disposal pathway, immediate action, safety considerations, and verified reuse or recovery alternatives.

---

## 🧩 Problem Statement

Improper waste segregation makes effective waste management more difficult.

People often struggle to determine:

- Which category a waste item belongs to 
- How it should be handled or disposed of 
- Whether it can be reused or recovered 
- How safety-sensitive waste should be handled 

EcoSense aims to make these decisions easier through a simple image-based interface.

---

## 💡 Proposed Solution

EcoSense allows a user to:

1. Capture or upload an image of a waste item.
2. Use AI to identify the primary item.
3. Match the identified item with a controlled knowledge base.
4. Display the appropriate waste pathway.
5. Show an immediate recommended action.
6. Provide safety guidance where necessary.
7. Suggest verified reuse, repurpose, composting, or recovery alternatives.
8. Rotate through different alternatives when the same item is scanned repeatedly.

---

## 🤖 How AI Is Used

EcoSense uses the **Google Gemini API** for image-based waste identification.

Gemini is responsible for identifying the primary waste item from the uploaded image.

The disposal guidance and alternative recommendations are **not freely generated by the AI**. Instead, the identified item is matched against a controlled `knowledge_base.json` file containing predefined guidance.

## 🏗️ Architecture

```text

User Image
     ↓
Gemini AI
     ↓
Waste Item Identification
     ↓
Controlled Knowledge Base
     ↓
Waste Pathway + Safety Guidance
     ↓
Alternative / Reuse Recommendation
     ↓
User

```
This approach helps reduce the risk of unsupported disposal or reuse instructions being generated by the AI.

## 🛡️ Safety Approach

EcoSense follows the principle:

Safety → Correct Disposal → Reuse → Extra Suggestions

For safety-sensitive items such as batteries, medicines, syringes, and sanitary products, the prototype prioritizes appropriate disposal or authorized collection pathways instead of suggesting unsafe DIY reuse.

## ⚙️ Installation

1. Clone the repository
```bash
git clone https://github.com/Manashvi-Ishita/EcoSense.git
```

2. Open the Project Directory
```bash
cd EcoSense
```

3. Create a virtual environment
```bash
python -m venv .venv
```

4. Activate the virtual environment 

```powershell
.venv\Scripts\Activate.ps1
```

5. Install dependencies
```bash
pip install -r requirements.txt
```

### Gemini API Key
EcoSense requires a Gemini API key for image-based identification.

Create a .env file in the project root:
```env
GEMINI_API_KEY=your_api_key_here
```

### Run the Application

After activating the virtual environment, run:

```bash
python app.py
```

Open the local address shown by Flask in your browser.
